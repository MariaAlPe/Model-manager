# Model Manager

Интерактивный прототип платформы управления универсальными финансовыми моделями банка.

## Возможности

- единый реестр моделей;
- переключение и фильтрация по режимам «План» и «Прогноз»;
- отдельные метки «План» и «Прогноз» у комбинированных моделей;
- роль текущего пользователя для каждой модели;
- карточка модели с паспортом, состоянием, сценарием и версией;
- разделы запусков, зависимостей, согласований и аудита;
- адаптивный интерфейс для телефона и компьютера.

## Запуск

Проект не требует сборки и внешних зависимостей. Откройте файл `index.html` в браузере.
